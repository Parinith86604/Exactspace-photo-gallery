# ExactSpace Photo Gallery

A responsive ReactJS Photo Gallery application developed as part of the ExactSpace Technologies Frontend/UI Developer internship assignment.

## Overview

The application fetches photographs from the Picsum Photos API and displays them in a clean, single-column gallery. Each photo includes author information and an independent like counter.

## Features

- Picsum Photos API integration
- Single-column responsive photo gallery
- Author information and independent like counters
- Infinite scrolling using IntersectionObserver
- Duplicate prevention
- Loading, error and retry states
- Image loading and failure handling

## Tech Stack

- React
- JavaScript
- Vite
- CSS
- Font Awesome
- Vitest
- React Testing Library

## Getting Started

Clone the repository:

    git clone https://github.com/Parinith86604/Exactspace-photo-gallery.git

Open the project folder:

    cd Exactspace-photo-gallery

Install dependencies:

    npm install

Start the development server:

    npm run dev

## Testing

    npm run test

## Production Build

    npm run build

Preview:

    npm run preview

## API

https://picsum.photos/v2/list?page=1
